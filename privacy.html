앱으로 돌아가기

개인정보처리방침

시행일 2026년 8월 13일

먼저 요약하면 이렇습니다.
  • 카드번호, 비밀번호, 금융기관 로그인 정보는 받지 않습니다.
  • 받는 것은 아이디와 이름, 그리고 직접 입력한 카드사와 카드명, 사용 시점, 캐시백 기록입니다.
  • 다른 이용자에게 이름이나 개별 기록이 보이지 않습니다. 인기 화면은 인원수만 셉니다.
  • 탈퇴하면 모두 삭제됩니다. 설정에서 바로 하실 수 있습니다.

1. 수집하는 항목

서비스 이용을 위해 아래 항목을 수집합니다.

구분항목수집 방법
계정아이디, 비밀번호, 표시 이름, 가입일시, 약관 동의 일시회원가입 시 직접 입력
카드카드사, 카드명, 국제브랜드, 발급채널, 발급일, 연회비, 최근 사용일, 상태, 해지일, 메모이용자가 직접 입력
프로모션이벤트명, 카드사, 채널, 응모 마감일, 신청일, 혜택 조건, 사용 금액, 캐시백 수령일과 금액, 이용자가 붙여넣은 공고 원문이용자가 직접 입력하거나 붙여넣기
문의문의 분류, 문의 내용, 이용자가 적은 연락처문의하기 이용 시

수집하지 않는 항목입니다. 카드번호, 유효기간, CVC, 비밀번호, 계좌번호, 주민등록번호, 카드사나 금융기관의 아이디와 비밀번호, 인증서, 실제 결제 내역 원본은 수집하지 않으며 입력받는 화면도 없습니다.

2. 이용 목적

  • 회원 식별과 로그인 유지
  • 입력한 카드 정보와 프로모션 조건을 대조해 응모 가능 여부와 일정을 계산하고 표시
  • 연도별 캐시백 결산 제공
  • 익명 통계 산출 (누가 무엇을 했는지는 포함하지 않습니다)
  • 문의 응대와 오류 확인

3. 보유 기간

회원 탈퇴 시 지체 없이 파기합니다. 설정 화면에서 직접 탈퇴하면 계정과 카드, 프로모션 기록이 즉시 삭제됩니다. 문의 내역은 응대 확인을 위해 접수일로부터 1년간 보관한 뒤 삭제합니다. 1년 이상 로그인하지 않은 계정은 안내 후 삭제할 수 있습니다.

4. 제3자 제공

이용자의 개인정보를 제3자에게 제공하지 않습니다. 다만 서비스 제공에 필요한 범위에서 아래를 이용합니다.

이용 대상내용보관 위치
Google (Google Workspace, Apps Script, Drive)데이터 저장과 서버 기능 수행Google 데이터센터
Google (Gemini API)이용자가 붙여넣은 공고 내용을 분석해 조건을 정리분석 요청 시에만 전송

공고 분석 기능은 이용자가 붙여넣은 공고 텍스트와 화면 캡처를 Google의 생성형 AI에 전송해 처리합니다. 카드사가 공개한 이벤트 안내를 넣는 기능이므로, 개인 계좌 화면이나 본인 정보가 담긴 화면은 넣지 마시기 바랍니다.

5. 다른 이용자에게 보이는 정보

다른 이용자에게 이름, 카드 내역, 사용 금액, 캐시백 수령 이력이 보이지 않습니다. 인기 화면은 "몇 명이 어느 카드사를 담아두었는지" 같은 인원수만 보여주며, 인원이 적어 개인이 특정될 수 있는 항목은 집계에서 제외합니다.

6. 안전조치

  • 비밀번호는 되돌릴 수 없는 형태(해시)로 저장하며 운영자도 원래 값을 알 수 없습니다.
  • 모든 통신은 HTTPS로 암호화됩니다.
  • 서버는 로그인한 본인의 데이터만 내려보내며, 다른 이용자의 기록은 조회하거나 수정할 수 없습니다.
  • 데이터가 저장된 Google 계정에는 2단계 인증을 적용합니다.

다만 이 서비스는 개인이 운영하는 소규모 서비스입니다. 금융기관 수준의 보안 체계를 갖추고 있지 않으므로, 민감한 내용은 입력하지 않으시기를 권합니다.

7. 이용자의 권리

이용자는 언제든 자신의 정보를 열람, 정정, 삭제할 수 있습니다. 앱에서 직접 수정하거나 삭제할 수 있고, 전체 삭제는 설정 화면의 탈퇴로 가능합니다. 그 밖의 요청은 아래 연락처로 알려 주시면 처리 후 알려 드립니다.
